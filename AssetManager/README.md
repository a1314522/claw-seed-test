# AssetManager 固定资产与消耗品管理系统

## 项目定位
内网部署的固定资产+消耗品全生命周期管理平台。
- **ERP（金蝶）负责**：采购、入账、生成资产卡片
- **本系统负责**：资产领用、调拨、维修、报废、盘点、耗材管理
- **数据同步**：从金蝶拉取组织架构 + 固定资产卡片

## 技术栈
- .NET 8 + Blazor Server
- Entity Framework Core + SQLite
- 扫码盘点（手机端友好）
- AD域登录（预留配置）

## 核心功能模块

### 1. 资产管理
- 资产台账：从金蝶同步资产卡片（名称、型号、SN、购置日期、价格、供应商）
- 资产生命周期：入库 → 领用/调拨 → 维修 → 报废
- 标签打印：一物一码（二维码），手机扫码查档案
- 扫码盘点：比对人账差异，生成盘点报告
- 折旧计算：按分类自动计算月折旧

### 2. 耗材管理
- 库存台账：物品名称、规格、库存量、预警阈值
- 出入库：领用申请 → 审批 → 出库，库存自动扣减
- 库存预警：低于阈值自动标红提醒

### 3. 组织架构同步
- 从金蝶K3 Cloud/Wise API同步部门、人员
- 定时同步 + 手动触发
- 同步日志记录

### 4. 审批流
- 领用审批、调拨审批、报废审批
- 自定义审批人（部门负责人→IT管理员→财务）

### 5. 系统设置
- 金蝶API配置（地址、账号、密钥）
- AD域配置（服务器、端口、BaseDN）
- 资产分类、耗材分类自定义

## 数据库模型
- `Asset` 资产主表
- `AssetLifecycle` 资产生命周期记录
- `Consumable` 耗材主表
- `ConsumableTransaction` 耗材出入库记录
- `OrganizationUnit` 组织架构（部门）
- `Employee` 人员
- `InventoryCheck` 盘点任务
- `InventoryCheckItem` 盘点明细
- `ApprovalFlow` 审批流
- `KingdeeSyncLog` 金蝶同步日志
- `SystemConfig` 系统配置

## 部署方式
内网IIS或Windows Service部署，SQLite单文件数据库，零额外依赖。
