# OpenClaw Workspace

This repository contains the development workspace for the OpenClaw PaaS infrastructure.

## Components

- **AIKnowledgeBase** - Knowledge management system (FastAPI + PostgreSQL + Redis)
- **AssetManagementSystem** - Asset tracking system (WPF/Desktop)
- **AssetManager** - Blazor web asset management interface
- **docs/** - Architecture documentation and schemas
- **memory/** - Conversation logs and memory entries

## Infrastructure

- PostgreSQL 15
- Redis 7
- Nginx
- OpenClaw Gateway
